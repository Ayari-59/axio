📖 Tiime : Maîtriser les 4 journaux

1. Journal de Ventes (VEN)

Enregistre toutes les factures client et les avoirs (remises, retours).

Quand l'utiliser : Dès que vous facturez un client

Structure d'une saisie

Champ Valeur type Explication
Date 2025-01-15 Date de la facture (période comptable)
Numéro pièce FAC-001 Référence unique (facture, bon d'accès)
Client Acme Corp Sélectionnez ou créez le tiers
Compte débité 4010 (Clients) Créance client (augmente l'actif)
Montant débit 1 000 € Montant TTC de la facture
Compte crédité 7010 (Ventes) Produit de l'activité
Montant crédit 1 000 € Doit égaler le débit
💡 Conseil : En réalité, les ventes incluent souvent la TVA. Tiime décompose automatiquement en 3 lignes :
- Débit Clients = TTC
- Crédit Ventes = HT
- Crédit TVA collectée = TVA
⚠️ Attention : Une facture non payée crée une créance (compte 4010 Clients). Le paiement ultérieur rapproche le client et la banque.

2. Journal d'Achats (ACH)

Enregistre toutes les factures fournisseur et les avoirs fournisseur.

Quand l'utiliser : Dès que vous recevez une facture fournisseur

Cas courants

Cas Compte débité Compte crédité Montant
Achat matières premières 6010 (Achats) 2010 (Fournisseurs) HT
Achat services (électricité, loyer) 6030 (Utilitaires) 2010 (Fournisseurs) HT
Achat équipement (immo) 2013 (Équipement) 2010 (Fournisseurs) HT
💡 Conseil : Tiime gère automatiquement la TVA déductible (4566 ou 4562 selon le type d'achat).
⚠️ Important : Les factures fournisseur impayées créent une dette (compte 2010 Fournisseurs). Vous avez une obligation de paiement.

3. Journal de Banque (BAN)

Enregistre tous les mouvements de trésorerie : virements, chèques, prélèvements, remises.

Quand l'utiliser : Chaque opération bancaire (paiement, reçu, frais)

Exemples courants

Opération Débit (1020) Crédit Explication
Dépôt argent en banque + (reçu) Caisse (1010) La banque augmente
Paiement fournisseur - (sorti) Fournisseurs (2010) Dépense + réduction dette
Encaissement client + (reçu) Clients (4010) Réduction créance client
Frais bancaires - (sorti) Frais (6050) Charge du mois
💡 Conseil : Saisissez les opérations du relevé bancaire directement. Tiime propose un mode "rapprochement" pour lettrer automatiquement.
⚠️ Règle clé : Le total du compte Banque dans Tiime doit correspondre au solde du relevé bancaire. C'est le point de contrôle mensuel principal.

4. Journal Général (JG)

Journal fourre-tout pour les écritures non-standard qui ne rentrent pas dans Ventes, Achats ou Banque.

Quand l'utiliser : Écritures de régularisation, reclassements, corrections

Exemples

  • Amortissement : Débit Charges (6800) / Crédit Amortissement (2801)
  • Provision : Débit Charges (6900) / Crédit Provision (1910)
  • Correction d'erreur : Pièce inverse de l'erreur
  • Reclassement : Débit/Crédit de deux comptes sans créer de double charge
  • Intérêts intercalaires : Débit Charges (6600) / Crédit Banque (1020)
⚠️ Attention : Le journal Général doit être utilisé avec parcimonie. Chaque écriture doit être justifiée par un document.

🎯 Workflow de saisie type

  1. Lundi matin : Consulter la boîte mail et le suivi des commandes
  2. Mardi : Saisir les factures client de la semaine précédente (Journal Ventes)
  3. Mercredi : Saisir les factures fournisseur reçues (Journal Achats)
  4. Jeudi : Relever la banque et saisir les opérations (Journal Banque)
  5. Vendredi : Vérifier la balance (débits = crédits) et générer un rapport
  6. Fin de mois : Écritures de régularisation (Journal Général)

✅ Checklist de validation

  • ✓ Tous les journaux sont renseignés
  • ✓ Les dates sont dans la bonne période comptable
  • ✓ Chaque pièce a une référence unique
  • ✓ Les débits égalent les crédits pour chaque ligne
  • ✓ La balance générale équilibre (débits totaux = crédits totaux)
  • ✓ La banque Tiime correspond au relevé réel
  • ✓ Chaque opération est justifiée (facture, relevé, contrat)
