📚 Guide Tiime : Vos 10 premiers jours

Jour 1 : Connexion et familiarisation

Jour 1

Objectif : Accès complet à Tiime

  • Créer votre compte Tiime Cloud
  • Confirmer votre adresse e-mail
  • Découvrir le tableau de bord principal
  • Identifier les 5 modules (Comptabilité, Ventes, Achats, Paie, Immo)

Jour 2-3 : Création de l'entreprise et paramétrage

J2-3

Objectif : Base prête à saisir

  • Créer une nouvelle entreprise (SARL, EURL, etc.)
  • Paramétrer : siège, régime TVA, exercice comptable
  • Charger le plan de comptes français (PCG standard)
  • Paramétrer les journaux : Ventes, Achats, Banque, Général

💡 Tiime propose des templates sectoriels : utilisez celui le plus proche de votre métier

Jour 4-5 : Première saisie comptable

J4-5

Objectif : Maîtriser la double-entrée

  • Ouvrir le journal Ventes
  • Saisir votre première facture client
  • Comprendre : débit (client) = crédit (revenu)
  • Consulter le grand livre et vérifier les soldes

✅ Chaque ligne saisie = une pièce. Toujours équilibrer : Débits = Crédits

Jour 6-7 : Saisie achats et gestion TVA

J6-7

Objectif : TVA collectée vs déductible

  • Saisir une facture fournisseur dans le journal Achats
  • Comprendre la TVA déductible (4566)
  • Saisir un paiement en banque
  • Vérifier le compte TVA collectée (4457)

📋 Comptes TVA français : 4457 (collectée), 4566 (déductible matières), 4562 (déductible immo)

Jour 8 : Écritures bancaires et lettrage

Jour 8

Objectif : Banque en accord avec le relev

  • Consulter le journal Banque
  • Saisir les opérations de votre relevé
  • Lettrer les factures payées
  • Vérifier la balance banque = relevé

Jour 9 : Consultation et analyse

Jour 9

Objectif : Lire la comptabilité

  • Consulter la balance générale (débits = crédits ?)
  • Lire le compte de résultat (revenu - charges)
  • Afficher le bilan (actif = passif ?)
  • Générer un export PDF

Jour 10 : Clôture et archivage

Jour 10

Objectif : Préparer la fin de l'exercice

  • Vérifier que toutes les opérations sont saisies
  • Contrôler la balance (débits = crédits)
  • Enregistrer les écritures de clôture si nécessaire
  • Exporter pour archive / contrôle externe

🎯 Prochaines étapes

  • Parcourir le module Ventes pour les factures clients
  • Parcourir le module Achats pour les factures fournisseurs
  • Paramétrer les tiers (clients, fournisseurs)
  • Mettre en place des budgets sectoriels
