COMPTES DE TVA FRANÇAIS - DÉTAIL
═══════════════════════════════════════════════════════════════════════════════

TVA COLLECTÉE (Classe 4)
────────────────────────
4457  TVA collectée
      → Utilisé : Quand vous facturez un client
      → Côté : Crédit (augmente la dette envers l'État)
      → Taux : 20% (normal), 10% (réduit), 5,5% (super-réduit), 0% (exempte)

TVA DÉDUCTIBLE (Classe 4)
──────────────────────────
4566  TVA déductible sur matières et fournitures
      → Utilisé : Achat de matériel de production
      → Côté : Crédit (réduit la dette envers l'État)

4562  TVA déductible sur immobilisations
      → Utilisé : Achat d'équipement/immeuble
      → Côté : Crédit (réduit la dette envers l'État)

4568  TVA déductible sur autres biens et services
      → Utilisé : Achat de services, fournitures générales
      → Côté : Crédit (réduit la dette envers l'État)

TVA À DÉCAISSER (Classe 4)
──────────────────────────
4472  TVA à décaisser
      → Solde = TVA collectée (4457) - TVA déductible (4566+4562)
      → Si > 0 : Vous devez payer l'État
      → Si < 0 : L'État vous doit un crédit (à reporter ou demander remboursement)

CHIFFRES CLÉS POUR TIIME
═══════════════════════════════════════════════════════════════════════════════

Exemple 1 : Achat de matériel 1 000 € HT avec TVA 20%
─────────────────────────────────────────────────────
Débit  2033 Équipements informatiques  : 1 000 €
Crédit 4562 TVA déductible immobilisations : 200 €
Crédit 2010 Fournisseurs            : 1 200 € (total TTC)

Exemple 2 : Vente de service 500 € HT avec TVA 20%
──────────────────────────────────────────────────
Débit  4010 Clients                 : 600 € (total TTC)
Crédit 7030 Prestations services    : 500 €
Crédit 4457 TVA collectée           : 100 €

Exemple 3 : Calcul TVA à décaisser mensuel
──────────────────────────────────────────
TVA collectée (4457)              : +100 €
TVA déductible matières (4566)    : -80 €
TVA déductible immobilisations (4562) : -20 €
─────────────────────────────────
TVA à décaisser (4472) fin mois   : = 0 €

→ Si = 0, solde zéro (ni à payer ni à récupérer)
→ Si > 0, vous versez à l'État
→ Si < 0, l'État vous doit (crédit TVA)

CONSEILS TIIME
═══════════════════════════════════════════════════════════════════════════════

1. Toujours vérifier la balance (débits = crédits)
2. Classer les comptes par activité pour un pilotage facile
3. Créer des comptes "analytiques" pour suivre par centre de coûts
4. Paramétrer les taux TVA par type de transaction
5. Rapprocher la banque tous les mois
6. Exporter trimestrialement pour la déclaration TVA
7. Conserver tous les justificatifs (factures, relevés, contrats)
8. Archiver les clôtures annuelles
